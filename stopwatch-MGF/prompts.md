# Role

You are a senior frontend developer.

# Goal

Build a Stopwatch and Countdown Timer web app inspired by the functionality of: https://www.online-stopwatch.com

The implementation must be simple, clean, and production-ready, using only HTML, CSS, and vanilla JavaScript.

# Project Structure

Use the following index.html file as the starting point:

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Timer and Countdown</title>
<link rel="stylesheet" href="styles.css">
</head>
<body>
<h1>Timer and Countdown</h1>
<script src="script.js"></script>
</body>
</html>
```

The main logic must be implemented in script.js.

# Functional Requirements

1. Stopwatch Mode

Implement a stopwatch with the following features:
- Start
- Pause
- Continue
- Clear

Display time in the format: `HH:MM:SS.ms`. Example: `00:01:25.34`

See uploaded file for UX/UI details.

2. Countdown Mode

Implement a countdown with the following features:
- Start
- Pause
- Continue
- Clear

Users can configure hours, minutes and seconds.

# Output

- index.html
- script.js
